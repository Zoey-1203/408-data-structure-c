# 数据结构与算法学习仓库

## 仓库简介

本仓库用于记录个人在计算机408数据结构与蓝桥杯程序设计竞赛备赛过程中的代码练习。

主要包含以下两个部分：

- **计算机408数据结构**：采用标准C语言实现线性表、栈与队列、二叉树、图及常见排序算法等核心内容，加深对数据结构底层原理的理解。
- **蓝桥杯C++程序设计**：面向蓝桥杯大学B组，使用C++进行基础语法、STL、常见算法及历年真题的练习，逐步提升算法设计与编程能力。

## 目录结构

### 一、计算机408数据结构（C语言）

- `c_basic`：C语言基础代码练习
- `linear_list`：线性表
  - `seq_list`：顺序表
  - `linked_list`：链表
    - `base_practice`：单链表、双向链表自主练习代码
    - `leetcode_exercise`：链表相关LeetCode习题代码
- `stack_queue`：栈与队列基础实现
- `tree`：二叉树遍历、二叉搜索树
- `graph`：图的DFS、BFS遍历
- `sort`：常见内部排序算法实现

### 二、蓝桥杯C++程序设计（计划逐步完善）

- `lanqiao_cpp`：蓝桥杯C++备赛练习
  - `cpp_basic`：C++基础语法练习
  - `notes`：C++基础语法练习相关笔记
  - `stl`：C++标准模板库练习
  - `basic_algorithm`：枚举、模拟、排序、前缀和、二分等基础算法
  - `search`：DFS、BFS及回溯算法
  - `dynamic_programming`：动态规划及背包问题
  - `math`：数学基础与数论算法
  - `graph_algorithm`：图论及最短路径算法
  - `past_papers`：蓝桥杯历年真题练习

## 学习目标

1. 通过C语言自主实现数据结构，加深对计算机408核心知识点的理解。
2. 系统学习C++及常见算法，逐步提升独立编程和算法解题能力。
3. 通过蓝桥杯历年真题训练，积累竞赛经验，以大学B组省赛一等奖为备赛目标。
4. 持续整理代码与学习记录，形成个人数据结构与算法知识体系。

## 说明

本仓库主要用于个人学习与练习，代码以自主实现为主，并根据学习进度持续更新。

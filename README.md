## 仓库简介
本仓库为计算机408自主实现的数据结构代码，全部采用标准C语言实现
包含线性表、栈队列、二叉树、图、各类排序算法等408核心代码

## 目录结构
- c_basic：C语言基础代码练习
- linear_list：线性表
  - seq_list：顺序表
  - linked_list：链表
    - base_practice：单链表、双向链表自主练习代码
    - leetcode_exercise：链表相关LeetCode习题代码
- stack_queue：栈与队列基础实现
- tree：二叉树遍历、二叉搜索树
- graph：图的DFS、BFS遍历
- sort：常见内部排序算法实现

所有代码均独立编写，用于巩固底层原理，持续更新

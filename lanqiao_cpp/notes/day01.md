# Day 1：C++基础程序结构

## 1. 基础知识

- #include <iostream>：引入标准输入输出流声明
- using namespace std;：方便使用标准库中的名称
- int main()：程序入口函数
- cout：标准输出对象
- <<：流插入运算符
- endl：换行并刷新输出缓冲区
- return 0;：结束main函数并返回成功状态
- ;：语句结束符

## 2. 编译与运行

- .cpp：C++源代码文件
- g++：C++编译器
- Run Code：快速编译并运行程序

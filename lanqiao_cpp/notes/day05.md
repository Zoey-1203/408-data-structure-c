# Day 5：C++ 条件判断进阶与逻辑运算符

## 一、知识点①：if-else 双分支判断

- `if`：当条件成立时，执行 if 中的代码。
- `else`：当 if 条件不成立时，执行 else 中的代码。
- `if-else`：根据条件在两个不同的执行分支中选择一个。
- 两个分支只会执行其中一个。
- `else` 后面不需要添加判断条件。

**C++ 示例**

```cpp
int score = 75;

if (score >= 60) {
    cout << "Pass" << endl;
} else {
    cout << "Fail" << endl;
}
```

**运行结果**

```text
Pass
```

## 二、知识点②：else if 多分支判断

- `else if`：用于判断多个不同的条件。
- 程序从上到下依次判断。
- 遇到第一个成立的条件，就执行对应代码。
- 执行后跳出整个 if-else if 结构。
- `else`：当前面所有条件都不成立时执行。
- 条件顺序很重要，通常按照从高到低排列。

**C++ 示例**

```cpp
int score = 85;

if (score >= 90) {
    cout << "Excellent" << endl;
} else if (score >= 80) {
    cout << "Good" << endl;
} else if (score >= 60) {
    cout << "Pass" << endl;
} else {
    cout << "Fail" << endl;
}
```

**运行结果**

```text
Good
```

## 三、知识点③：嵌套 if 判断

- 嵌套 if：在一个 `if` 语句内部，再写一个 `if` 语句。
- 程序首先判断外层条件。
- 外层条件成立，才会进入内层继续判断。
- 每一层 if 都可以有自己的 `else`。
- 内层的 `else` 与内层的 `if` 配对，外层的 `else` 与外层的 `if` 配对。
- 嵌套 if 可以用于需要多个条件逐层判断的场景。

**C++ 示例**

```cpp
int age = 20;
int score = 85;

if (age >= 18) {
    if (score >= 60) {
        cout << "Pass" << endl;
    } else {
        cout << "Fail" << endl;
    }
} else {
    cout << "Too young" << endl;
}
```

**运行结果**

```text
Pass
```

## 四、知识点④：逻辑与运算符 `&&`

- `&&`：表示逻辑与（AND）。
- 两个条件都成立，整个表达式才为 `true`。
- 只要有一个条件不成立，结果就是 `false`。
- 常用于多个条件必须同时满足的情况。
- `and` 是 C++ 中 `&&` 的另一种合法写法。

**逻辑与真值表**

| 条件1 | 条件2 | 结果 |
|---|---|---|
| true | true | true |
| true | false | false |
| false | true | false |
| false | false | false |

**C++ 示例**

```cpp
int age = 20;
int score = 85;

if (age >= 18 && score >= 60) {
    cout << "Pass" << endl;
} else {
    cout << "Fail" << endl;
}
```

**运行结果**

```text
Pass
```

## 五、知识点⑤：逻辑或运算符 `||`

- `||`：表示逻辑或（OR）。
- 两个条件中只要有一个成立，整个表达式就为 `true`。
- 只有两个条件都不成立时，结果才为 `false`。
- 常用于多个条件满足其中一个即可的场景。
- `||` 具有短路特性：如果第一个条件已经为真，第二个条件就不会再执行。

**逻辑或真值表**

| 条件1 | 条件2 | 结果 |
|---|---|---|
| false | false | false |
| false | true | true |
| true | false | true |
| true | true | true |

**C++ 示例**

```cpp
int a = 5;
int b = 8;

if (a > 10 || b > 5) {
    cout << "Yes" << endl;
} else {
    cout << "No" << endl;
}
```

**运行结果**

```text
Yes
```

## 六、知识点⑥：逻辑非运算符 `!`

- `!`：表示逻辑非（NOT），也叫逻辑取反。
- 将原来的判断结果反过来。
- `true` 取反后变成 `false`。
- `false` 取反后变成 `true`。
- 常用于判断某个条件是否不成立。
- `!` 只改变逻辑判断结果，不改变变量本身的值。

**逻辑非真值表**

| 原来的结果 | 取反后的结果 |
|---|---|
| true | false |
| false | true |

**C++ 示例**

```cpp
int a = 8;

if (!(a > 10)) {
    cout << "A" << endl;
} else {
    cout << "B" << endl;
}
```

**运行结果**

```text
A
```

**计算过程**

1. `a > 10`：8 大于 10，结果为 false。
2. `!(false)`：取反后变成 true。
3. 条件成立，执行 if 中的代码。

## 七、三种逻辑运算符总结

| 运算符 | 名称 | 作用 |
|---|---|---|
| `&&` | 逻辑与 | 两个条件都成立 |
| `||` | 逻辑或 | 至少一个条件成立 |
| `!` | 逻辑非 | 将判断结果取反 |

**记忆口诀：**

- `&&`：两个都要满足。
- `||`：满足一个就可以。
- `!`：真假颠倒。

## 一、知识点①：数组的概念

### 1. 什么是数组？

数组（Array）是一种可以存储多个相同类型数据的数据结构。

例如：

如果需要存储5个学生的成绩，可以使用5个独立变量：

```cpp
int score1 = 85;
int score2 = 90;
int score3 = 76;
int score4 = 92;
int score5 = 88;
```

也可以使用一个数组：

```cpp
int score[5] = {85, 90, 76, 92, 88};
```

数组可以把多个同类型的数据集中管理。

### 2. 数组的特点

- 数组中的元素必须是相同的数据类型。
- 数组有固定的长度。
- 数组中的每个元素都有自己的下标。
- 数组下标从0开始。
- 可以通过数组名和下标访问元素。
- 数组元素在内存中连续存储。

### 3. 数组的结构

```text
数组名：score

下标：  0    1    2    3    4
       |    |    |    |    |
数据： 85   90   76   92   88
```

例如：

```cpp
cout << score[0];
```

输出：

```text
85
```

**核心记忆：数组就是一个名字管理多个同类型数据。**

## 二、知识点②：数组的定义

### 1. 基本格式

```cpp
数据类型 数组名[数组长度];
```

例如：

```cpp
int a[5];
```

含义：

- `int`：数组元素的数据类型。
- `a`：数组名称。
- `5`：数组长度，表示可以存储5个整数。

### 2. 不同类型的数组

```cpp
int a[5];       // 整数数组
double b[5];    // 小数数组
char c[10];     // 字符数组
```

### 3. 注意事项

```cpp
int a[5];
```

这个数组只能通过合法下标访问：

```cpp
a[0]
a[1]
a[2]
a[3]
a[4]
```

不能访问：

```cpp
a[5];
```

因为数组长度是5，下标范围是0～4。

**核心记忆：数组长度为n，下标范围就是0～n-1。**

## 三、知识点③：数组的初始化

初始化就是在定义数组时给数组元素赋初始值。

### 1. 完整初始化

```cpp
int a[5] = {10, 20, 30, 40, 50};
```

对应关系：

| 下标 | 元素值 |
|---|---:|
| a[0] | 10 |
| a[1] | 20 |
| a[2] | 30 |
| a[3] | 40 |
| a[4] | 50 |

### 2. 部分初始化

```cpp
int a[5] = {10, 20};
```

结果：

```text
10 20 0 0 0
```

没有明确赋值的剩余元素会自动初始化为0。

### 3. 自动推导数组长度

```cpp
int a[] = {10, 20, 30, 40, 50};
```

编译器可以根据初始化元素的数量确定数组长度。

这里数组长度为5。

### 4. 未初始化的数组

```cpp
int a[5];
```

如果这是函数内部定义的普通局部数组，元素不会自动变成0，不能直接假设里面的数据有效。

需要先赋值或输入，再使用。

**核心记忆：**

- 完整初始化：每个元素都有初始值。
- 部分初始化：剩余元素补0。
- 局部数组未初始化：不要直接读取。

## 四、知识点④：数组下标

数组下标用于访问数组中的某一个元素。

### 1. 下标从0开始

```cpp
int a[5] = {15, 25, 35, 45, 55};
```

| 下标 | 元素 |
|---|---:|
| 0 | 15 |
| 1 | 25 |
| 2 | 35 |
| 3 | 45 |
| 4 | 55 |

### 2. 访问指定元素

```cpp
cout << a[0] << endl;
cout << a[2] << endl;
cout << a[4] << endl;
```

输出：

```text
15
35
55
```

### 3. 使用变量访问元素

```cpp
for (int i = 0; i < 5; i++) {
    cout << a[i] << endl;
}
```

这里：

- `i = 0`，访问a[0]。
- `i = 1`，访问a[1]。
- `i = 2`，访问a[2]。
- `i = 3`，访问a[3]。
- `i = 4`，访问a[4]。

### 4. 易错点

```cpp
for (int i = 0; i <= 5; i++)
```

这是错误的遍历范围，因为会访问a[5]。

正确写法：

```cpp
for (int i = 0; i < 5; i++)
```

**核心记忆：数组长度为5，循环条件通常使用i < 5。**

## 五、知识点⑤：数组的输入与输出

### 1. 定义数组

```cpp
int a[5];
```

### 2. 输入数组元素

```cpp
for (int i = 0; i < 5; i++) {
    cin >> a[i];
}
```

循环会执行5次。

每次输入一个整数，存入对应位置。

### 3. 输出数组元素

```cpp
for (int i = 0; i < 5; i++) {
    cout << a[i] << endl;
}
```

### 4. 完整示例

```cpp
#include <iostream>
using namespace std;

int main() {

    int a[5];

    // 输入5个整数
    for (int i = 0; i < 5; i++) {
        cin >> a[i];
    }

    // 输出5个整数
    for (int i = 0; i < 5; i++) {
        cout << a[i] << endl;
    }

    return 0;
}
```

输入：

```text
10 20 30 40 50
```

输出：

```text
10
20
30
40
50
```

### 5. 两个循环可以使用相同的循环变量吗？

可以。

例如：

```cpp
for (int i = 0; i < 5; i++) {
    cin >> a[i];
}

for (int i = 0; i < 5; i++) {
    cout << a[i] << endl;
}
```

因为每个for循环中定义的i只在自己的循环作用域内有效。

两个循环互不冲突。

**核心记忆：一个循环负责输入，另一个循环负责输出。**

## 六、知识点⑥：数组元素求和

### 1. 基本思路

数组求和就是把数组中的所有元素依次加起来。

例如：

```text
10 20 30 40 50
```

计算：

```text
10 + 20 + 30 + 40 + 50 = 150
```

### 2. 关键代码

首先定义一个变量：

```cpp
int sum = 0;
```

为什么初始化为0？

因为0是累加的起点。

然后遍历数组：

```cpp
for (int i = 0; i < 5; i++) {
    sum += a[i];
}
```

其中：

```cpp
sum += a[i];
```

等价于：

```cpp
sum = sum + a[i];
```

### 3. 完整示例

```cpp
#include <iostream>
using namespace std;

int main() {

    int a[5];
    int sum = 0;

    // 输入数组
    for (int i = 0; i < 5; i++) {
        cin >> a[i];
    }

    // 计算总和
    for (int i = 0; i < 5; i++) {
        sum += a[i];
    }

    cout << "sum = " << sum << endl;

    return 0;
}
```

### 4. 完整计算过程

输入：

```text
10 20 30 40 50
```

| 执行次数 | 当前元素 | sum变化 |
|---|---:|---:|
| 初始 | — | 0 |
| 第1次 | 10 | 10 |
| 第2次 | 20 | 30 |
| 第3次 | 30 | 60 |
| 第4次 | 40 | 100 |
| 第5次 | 50 | 150 |

最终：

```text
sum = 150
```

**核心记忆：sum负责保存累计结果，sum += a[i]负责不断累加。**

## 七、知识点⑦：数组元素求平均值

### 1. 基本公式

平均值 = 所有元素的总和 ÷ 元素个数。

\[
avg=\frac{sum}{n}
\]

例如：

```text
10 20 30 40 50
```

总和：

```text
150
```

元素个数：

```text
5
```

平均值：

```text
150 / 5 = 30
```

### 2. 关键代码

```cpp
int sum = 0;

for (int i = 0; i < 5; i++) {
    sum += a[i];
}

double avg = sum / 5.0;
```

### 3. 为什么使用5.0而不是5？

错误写法：

```cpp
double avg = sum / 5;
```

因为sum和5都是整数，执行的是整数除法，可能丢失小数部分。

正确写法：

```cpp
double avg = sum / 5.0;
```

因为5.0是浮点数，计算结果可以保留小数部分。

### 4. 完整示例

```cpp
#include <iostream>
using namespace std;

int main() {

    int a[5];
    int sum = 0;

    for (int i = 0; i < 5; i++) {
        cin >> a[i];
    }

    for (int i = 0; i < 5; i++) {
        sum += a[i];
    }

    double avg = sum / 5.0;

    cout << "sum = " << sum << endl;
    cout << "avg = " << avg << endl;

    return 0;
}
```

输入：

```text
10 20 30 40 50
```

输出：

```text
sum = 150
avg = 30
```

**核心记忆：求平均值先求总和，再除以元素个数，注意使用浮点数除法。**

## 八、知识点⑧：数组最大值与最小值

### 1. 基本思路

遍历数组，逐个比较元素。

- 如果当前元素比最大值大，就更新最大值。
- 如果当前元素比最小值小，就更新最小值。

### 2. 初始化

```cpp
int max = a[0];
int min = a[0];
```

为什么都使用a[0]？

因为先假设第一个元素既是最大值，也是最小值。

后续再通过比较更新。

### 3. 比较代码

```cpp
for (int i = 1; i < 5; i++) {

    if (a[i] > max) {
        max = a[i];
    }

    if (a[i] < min) {
        min = a[i];
    }
}
```

注意：这里从i=1开始，因为a[0]已经参与初始化。

### 4. 完整示例

```cpp
#include <iostream>
using namespace std;

int main() {

    int a[5];

    for (int i = 0; i < 5; i++) {
        cin >> a[i];
    }

    int max = a[0];
    int min = a[0];

    for (int i = 1; i < 5; i++) {

        if (a[i] > max) {
            max = a[i];
        }

        if (a[i] < min) {
            min = a[i];
        }
    }

    cout << "max = " << max << endl;
    cout << "min = " << min << endl;

    return 0;
}
```

输入：

```text
12 5 28 9 16
```

### 5. 完整比较过程

初始：

```text
max = 12
min = 12
```

| 当前元素 | 最大值判断 | 最小值判断 | 最终max | 最终min |
|---|---|---|---:|---:|
| 12 | 初始化 | 初始化 | 12 | 12 |
| 5 | 不更新 | 更新 | 12 | 5 |
| 28 | 更新 | 不更新 | 28 | 5 |
| 9 | 不更新 | 不更新 | 28 | 5 |
| 16 | 不更新 | 不更新 | 28 | 5 |

最终：

```text
max = 28
min = 5
```

**核心记忆：**

- max负责寻找最大值。
- min负责寻找最小值。
- 两个if分别判断。
- 初始化使用a[0]。

## 九、知识点⑨：数组元素查找

### 1. 基本思路

在数组中寻找指定的数字。

例如：

```text
数组：10 20 30 40 50
目标：30
```

需要逐个比较，直到找到目标。

### 2. 三个关键变量

```cpp
int target;
int index = -1;
```

- `target`：要查找的数字。
- `index`：记录目标元素所在的下标。
- `-1`：表示暂时没有找到。

### 3. 查找代码

```cpp
for (int i = 0; i < 5; i++) {

    if (a[i] == target) {
        index = i;
        break;
    }
}
```

其中：

```cpp
index = i;
```

表示记录找到的位置。

```cpp
break;
```

表示找到之后立即退出循环。

### 4. 完整示例

```cpp
#include <iostream>
using namespace std;

int main() {

    int a[5];

    for (int i = 0; i < 5; i++) {
        cin >> a[i];
    }

    int target;
    cin >> target;

    int index = -1;

    for (int i = 0; i < 5; i++) {

        if (a[i] == target) {
            index = i;
            break;
        }
    }

    if (index == -1) {
        cout << "没有找到" << endl;
    }
    else {
        cout << "找到了，下标为：" << index << endl;
    }

    return 0;
}
```

### 5. 找到目标的执行过程

输入：

```text
10 20 30 40 50
30
```

| i | a[i] | 是否等于30 |
|---|---:|---|
| 0 | 10 | 否 |
| 1 | 20 | 否 |
| 2 | 30 | 是 |

找到后：

```cpp
index = 2;
break;
```

输出：

```text
找到了，下标为：2
```

### 6. 没有找到的情况

输入：

```text
10 20 30 40 50
99
```

五次比较都不满足条件。

因此：

```cpp
index = -1;
```

最后执行：

```cpp
if (index == -1)
```

输出：

```text
没有找到
```

**核心记忆：**

- index = -1：默认没找到。
- index = i：记录下标。
- break：找到后退出循环。
- 最后通过if-else判断结果。

## 十、知识点⑩：数组元素统计

### 1. 基本思路

数组统计就是统计满足某种条件的元素数量。

例如：

```cpp
int a[5] = {6, 3, 10, 5, 8};
```

统计其中有多少个偶数。

### 2. 定义计数器

```cpp
int count = 0;
```

count用于记录符合条件的元素数量。

### 3. 判断偶数

```cpp
if (a[i] % 2 == 0) {
    count++;
}
```

其中：

- `%` 是取余运算符。
- 偶数除以2余数为0。
- `count++` 表示计数器加1。

### 4. 完整示例

```cpp
#include <iostream>
using namespace std;

int main() {

    int a[5] = {6, 3, 10, 5, 8};

    int count = 0;

    for (int i = 0; i < 5; i++) {

        if (a[i] % 2 == 0) {
            count++;
        }
    }

    cout << count;

    return 0;
}
```

### 5. 完整计算过程

| 元素 | 是否为偶数 | count |
|---|---|---:|
| 6 | 是 | 1 |
| 3 | 否 | 1 |
| 10 | 是 | 2 |
| 5 | 否 | 2 |
| 8 | 是 | 3 |

最终：

```text
3
```

### 6. 统计奇数

```cpp
if (a[i] % 2 != 0) {
    count++;
}
```

奇数除以2，余数不等于0。

### 7. 统计偶数与奇数的区别

| 统计目标 | 判断条件 |
|---|---|
| 偶数 | `a[i] % 2 == 0` |
| 奇数 | `a[i] % 2 != 0` |

**核心记忆：count负责计数，满足条件就执行count++。**

# 十一、二维数组与嵌套循环

二维数组是 Day 7 综合复习的重要内容。

## 1. 二维数组的概念

二维数组可以理解为一个表格，有行和列。

例如：

```cpp
int a[2][3] = {
    {7, 2, 9},
    {4, 1, 6}
};
```

表示：

- 2行。
- 3列。
- 一共6个元素。

对应表格：

| 行\列 | 第0列 | 第1列 | 第2列 |
|---|---:|---:|---:|
| 第0行 | 7 | 2 | 9 |
| 第1行 | 4 | 1 | 6 |

## 2. 二维数组的访问

```cpp
a[i][j]
```

其中：

- i控制行。
- j控制列。

例如：

```cpp
cout << a[0][1];
```

输出：

```text
2
```

## 3. 二维数组的遍历

二维数组通常使用嵌套循环。

```cpp
for (int i = 0; i < 2; i++) {

    for (int j = 0; j < 3; j++) {

        cout << a[i][j] << " ";
    }

    cout << endl;
}
```

输出：

```text
7 2 9
4 1 6
```

## 4. 外层循环与内层循环如何配合？

这是必须掌握的重点。

```cpp
for (int i = 0; i < 2; i++) {

    for (int j = 0; j < 3; j++) {

        cout << a[i][j] << " ";
    }

    cout << endl;
}
```

执行过程：

**第一次外层循环：i = 0**

内层循环完整执行：

```text
j = 0 → a[0][0] = 7
j = 1 → a[0][1] = 2
j = 2 → a[0][2] = 9
```

输出：

```text
7 2 9
```

内层循环结束。

**第二次外层循环：i = 1**

内层循环重新从j=0开始：

```text
j = 0 → a[1][0] = 4
j = 1 → a[1][1] = 1
j = 2 → a[1][2] = 6
```

输出：

```text
4 1 6
```

最终执行6次。

### 重要规律

- 外层循环控制行。
- 内层循环控制列。
- 每执行一次外层循环，内层循环完整执行一次。
- 总执行次数 = 行数 × 列数。

---

## 十二、二维数组综合应用

### 1. 统计二维数组中的偶数

```cpp
int a[2][3] = {
    {7, 2, 9},
    {4, 1, 6}
};

int count = 0;

for (int i = 0; i < 2; i++) {

    for (int j = 0; j < 3; j++) {

        if (a[i][j] % 2 == 0) {
            count++;
        }
    }
}

cout << count;
```

偶数为：

```text
2 4 6
```

最终：

```text
count = 3
```

### 2. 计算二维数组中偶数的总和

```cpp
int sum = 0;

for (int i = 0; i < 2; i++) {

    for (int j = 0; j < 3; j++) {

        if (a[i][j] % 2 == 0) {
            sum += a[i][j];
        }
    }
}

cout << sum;
```

计算：

```text
2 + 4 + 6 = 12
```

最终：

```text
sum = 12
```

### 3. 寻找二维数组最大值

```cpp
int max = a[0][0];

for (int i = 0; i < 2; i++) {

    for (int j = 0; j < 3; j++) {

        if (a[i][j] > max) {
            max = a[i][j];
        }
    }
}

cout << max;
```

最终：

```text
max = 9
```

### 4. 同时寻找最大值和最小值

```cpp
int max = a[0][0];
int min = a[0][0];

for (int i = 0; i < 2; i++) {

    for (int j = 0; j < 3; j++) {

        if (a[i][j] > max) {
            max = a[i][j];
        }

        if (a[i][j] < min) {
            min = a[i][j];
        }
    }
}

cout << "max = " << max << endl;
cout << "min = " << min << endl;
```

最终：

```text
max = 9
min = 1
```

最大值和最小值的和：

```text
9 + 1 = 10
```

### 5. 两个if为什么不能随意改成if-else？

```cpp
if (a[i][j] > max) {
    max = a[i][j];
}

if (a[i][j] < min) {
    min = a[i][j];
}
```

这两个判断分别负责最大值和最小值的更新。

使用两个独立的if，逻辑更加清晰，也能独立判断两个条件。

# 十三、Day 7 综合编程练习

## practice44.cpp：数组综合统计程序

### 1. 任务要求

输入5个整数，实现：

1. 计算总和。
2. 计算平均值。
3. 找出最大值。
4. 找出最小值。
5. 统计偶数个数。

### 2. 完整代码

```cpp
#include <iostream>
using namespace std;

int main() {

    int a[5];

    // 输入数组
    for (int i = 0; i < 5; i++) {
        cin >> a[i];
    }

    int sum = 0;
    int max = a[0];
    int min = a[0];
    int count = 0;

    // 计算总和、统计偶数
    for (int i = 0; i < 5; i++) {

        sum += a[i];

        if (a[i] % 2 == 0) {
            count++;
        }
    }

    // 寻找最大值和最小值
    for (int i = 1; i < 5; i++) {

        if (a[i] > max) {
            max = a[i];
        }

        if (a[i] < min) {
            min = a[i];
        }
    }

    // 计算平均值
    double avg = sum / 5.0;

    // 输出结果
    cout << "数组总和：" << sum << endl;
    cout << "数组平均值：" << avg << endl;
    cout << "最大值：" << max << endl;
    cout << "最小值：" << min << endl;
    cout << "偶数个数：" << count << endl;

    return 0;
}
```

### 3. 测试数据

```

输出：

```

## practice45.cpp：数组元素查找程序

### 1. 任务要求

输入5个整数，再输入一个目标数字。

要求：

- 找到目标数字，输出下标。
- 没有找到，输出没有找到。

### 2. 完整代码

```cpp
#include <iostream>
using namespace std;

int main() {

    int a[5];

    // 输入数组
    for (int i = 0; i < 5; i++) {
        cin >> a[i];
    }

    // 输入查找目标
    int target;
    cin >> target;

    // 默认没有找到
    int index = -1;

    // 开始查找
    for (int i = 0; i < 5; i++) {

        if (target == a[i]) {
            index = i;
            break;
        }
    }

    // 输出查找结果
    if (index == -1) {
        cout << "没有找到" << endl;
    }
    else {
        cout << "找到了，下标为：" << index << endl;
    }

    return 0;
}
```

### 3. 找到目标的测试

输入：

```text
10 20 30 40 50
30
```

输出：

```text
找到了，下标为：2
```

### 4. 没有找到的测试

输入：

```text
10 20 30 40 50
99
```

输出：

```text
没有找到
```

### 5. 核心执行逻辑

```cpp
int index = -1;
```

初始化为-1，表示还没有找到。

```cpp
if (target == a[i]) {
    index = i;
    break;
}
```

找到目标：

1. 记录当前下标。
2. 使用break退出循环。

```cpp
if (index == -1)
```

最后判断是否找到。

# 十七、Day 7 最重要的学习总结

数组学习的核心其实就是四个动作：

**1. 输入：把数据放进数组。**

```cpp
cin >> a[i];
```

**2. 遍历：使用循环访问每个元素。**

```cpp
for (int i = 0; i < 5; i++)
```

**3. 处理：根据题目要求计算、比较或统计。**

```cpp
sum += a[i];

if (a[i] > max) {
    max = a[i];
}

if (a[i] % 2 == 0) {
    count++;
}
```

**4. 输出：打印最终结果。**

```cpp
cout << sum << endl;
```

无论是求和、求平均值、寻找最大值、寻找最小值，还是统计元素数量，本质上都是：

> 使用for循环遍历数组，再通过不同的运算和if判断处理每个元素。

二维数组则是在一维数组的基础上增加了一层循环。

# Day 2：C++变量、数据类型与输入

## 1. 变量

变量用于保存数据。

```cpp
int age = 20;
```

- `int`：整数类型
- `age`：变量名
- `20`：变量的初始值

## 2. 基本数据类型

| 类型 | 作用 | 示例 |
|---|---|---|
| int | 整数 | `int age = 20;` |
| double | 浮点数 | `double score = 95.5;` |
| char | 单个字符 | `char grade = 'A';` |

注意：

- 字符使用单引号，例如 `'A'`。
- 字符串使用双引号，例如 `"Hello"`。
- `double` 通常用于需要小数的计算。

## 3. 变量赋值与修改

```cpp
int score = 80;
score = 95;
```

- 定义变量时需要声明类型。
- 修改已有变量的值时，不需要再次声明类型。
- `=` 是赋值运算符。

## 4. cin 标准输入

```cpp
int age;
double height;

cin >> age >> height;
```

- `cin`：标准输入对象。
- `>>`：流提取运算符。
- 可以连续读取多个变量。
- 输入数据可以通过空格或换行分隔。

## 5. cout 标准输出

```cpp
cout << "Age: " << age << endl;
```

- `cout`：标准输出对象。
- `<<`：流插入运算符。
- `endl`：换行并刷新输出缓冲区。

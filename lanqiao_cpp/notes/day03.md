# Day 3：C++ 算术运算符

## 1. 基本算术运算符

| 运算符 | 含义 | 示例 | 结果 |
|---|---|---|---|
| `+` | 加法 | `10 + 5` | 15 |
| `-` | 减法 | `10 - 5` | 5 |
| `*` | 乘法 | `10 * 5` | 50 |
| `/` | 除法 | `10 / 3` | 3 |
| `%` | 取模（取余数） | `10 % 3` | 1 |

## 2. 加减乘法

```cpp
int a = 10;
int b = 5;

cout << a + b << endl;
cout << a - b << endl;
cout << a * b << endl;
```

可以使用变量保存运算结果，也可以直接通过cout输出。

## 3. 整数除法与浮点数除法

```cpp
int a = 9;
int b = 2;

cout << a / b << endl;      // 4
cout << 1.0 * a / b << endl; // 4.5
```

注意：

- 两个int进行除法，结果为整数，小数部分向零截断。
- 有浮点数参与除法时，可以得到浮点数结果。
- 将整数除法的结果存入double变量，不能恢复已经丢失的小数部分。
- 除数不能为0。

## 4. 取模运算符

`%` 用于计算整数除法的余数。

```cpp
cout << 17 / 5 << endl; // 3
cout << 17 % 5 << endl; // 2
```

因为：

17 = 5 × 3 + 2

取模经常用于判断奇偶数、循环规律和数字处理。

注意：`%` 不能直接用于double类型的浮点数。

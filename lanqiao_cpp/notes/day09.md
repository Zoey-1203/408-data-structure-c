## 二、七个基础知识点

### ① 变量的内存地址：`&`

普通变量保存的是**值**，取地址运算符 `&` 可以获得变量所在的内存地址。

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 10;
    cout << "a = " << a << endl;
    cout << "&a = " << &a << endl;
    return 0;
}
```

运行结果（地址每次运行可能不同）：

```text
a = 10
&a = 0x...（实际地址）
```

- `a`：读取变量的值，结果为 10。
- `&a`：取得变量 `a` 的地址。
- 地址一般以十六进制形式显示，**不要把示例地址当成固定结果**。

### ② 指针变量：`int* p = &a;`

指针变量用来保存某个对象的地址。

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 20;
    int* p = &a;
    cout << a << endl;
    cout << p << endl;
    return 0;
}
```

输出第一行是 `20`，第二行是地址（具体地址不固定）。

| 表达式 | 含义 |
|---|---|
| `int a = 20;` | 定义整型变量 `a` |
| `int* p;` | 定义指向 `int` 的指针 `p` |
| `p = &a;` | 把 `a` 的地址存入 `p` |
| `p` | 指针保存的地址 |
| `&a` | `a` 的地址 |

> `int* p` 中的 `*` 是**声明指针**；表达式 `*p` 中的 `*` 是**解引用**。虽然符号相同，作用不同。

### ③ 解引用运算符：`*p`

当 `p` 指向有效的整型对象时，`*p` 表示该对象本身，可用于读取它的值。

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 30;
    int* p = &a;
    cout << a << endl;
    cout << *p << endl;
    return 0;
}
```

```text
30
30
```

思考顺序：`p` → 找到 `a` 的地址 → `*p` → 读取 `a` 的值 30。

### ④ 通过指针修改原变量

`*p` 不仅可以读取，还可以修改指向的原变量。

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 10;
    int* p = &a;
    *p = 100;
    cout << a << endl;
    cout << *p << endl;
    return 0;
}
```

```text
100
100
```

执行过程：`a=10` → `p` 指向 `a` → `*p=100` 修改 `a` → `a` 和 `*p` 均为 100。

**必须区分：** `p = ...` 修改指针保存的地址；`*p = ...` 修改当前指向的对象。

### ⑤ 指针作为函数参数

函数形参 `int* p` 接收一个地址。函数内部通过 `*p` 可以修改调用者的原变量。

```cpp
#include <iostream>
using namespace std;

void doubleNum(int* p) {
    *p = *p * 2;
}

int main() {
    int num = 15;
    cout << "调用前 num = " << num << endl;
    doubleNum(&num);
    cout << "调用后 num = " << num << endl;
    return 0;
}
```

```text
调用前 num = 15
调用后 num = 30
```

执行过程：

1. `num` 初始为 15。
2. `doubleNum(&num)` 将 `num` 的地址传入函数。
3. 形参 `p` 保存这份地址，`*p` 对应原来的 `num`。
4. `*p = *p * 2` 使 `num` 变成 30。
5. 函数返回，形参 `p` 生命周期结束，但 `num=30` 保留。

**重点：指针形参仍然是按值传递。** 传入的是地址值的副本。函数内部改变 `p` 自身（如 `p++`）不会改变调用者的指针变量；但通过 `*p` 可以改变它们共同指向的对象。

### ⑥ 指针与数组

数组名 `arr` 在 `int* p = arr;` 这样的表达式中会转换为首元素的地址，即 `&arr[0]`。

```cpp
#include <iostream>
using namespace std;

int main() {
    int arr[3] = {12, 24, 36};
    int* p = arr;

    cout << "arr[0] = " << arr[0] << endl;
    cout << "*p = " << *p << endl;
    cout << "arr[1] = " << arr[1] << endl;
    cout << "arr[2] = " << arr[2] << endl;
    return 0;
}
```

```text
arr[0] = 12
*p = 12
arr[1] = 24
arr[2] = 36
```

关系：

| 写法 | 本例中的含义 |
|---|---|
| `arr` | 在这里转换为 `&arr[0]` |
| `&arr[0]` | 首元素地址 |
| `p` | 保存首元素地址 |
| `*p` | `arr[0]`，值为 12 |
| `arr[1]` | 第二个元素，值为 24 |
| `arr[2]` | 第三个元素，值为 36 |

> 严格说来，数组名不是指针变量；只是在很多表达式中会发生“数组到指针”的转换，因此不能将 `arr` 和独立的指针变量 `p` 完全等同。

### ⑦ 指针移动：`p++`

对数组元素指针执行 `p++`，指针向后移动**一个对应类型的元素**，而不是固定移动 1 字节。

```cpp
#include <iostream>
using namespace std;

int main() {
    int arr[4] = {8, 16, 24, 32};
    int* p = arr;

    cout << *p << endl;
    p++;
    cout << *p << endl;
    p++;
    cout << *p << endl;
    p++;
    cout << *p << endl;
    return 0;
}
```

```text
8
16
24
32
```

| 时刻 | p 指向 | `*p` |
|---|---|---:|
| 初始化后 | `arr[0]` | 8 |
| 第 1 次 `p++` 后 | `arr[1]` | 16 |
| 第 2 次 `p++` 后 | `arr[2]` | 24 |
| 第 3 次 `p++` 后 | `arr[3]` | 32 |

**容易混淆的四个表达式：**

```cpp
p++;         // 移动指针，不改变数组元素
(*p)++;     // 当前指向的元素加 1，不移动指针
*(p + 1);   // 访问下一个元素，不改变 p 自身
*p = 100;   // 把当前指向的元素改成 100
```

**边界规则：** 可以形成指向数组最后一个元素之后的指针（one-past-the-end），但不能对它进行 `*p` 解引用；也不能越过合法指针运算范围。

### Practice60：独立综合编程（完整代码）

要求：对数组 `{12, 5, 28, 9, 16, 3}`，分别编写函数求最大值、最小值与偶数之和。下面按已完成的代码逻辑整理成可直接编译的版本。

```cpp
#include <iostream>
using namespace std;

int findMax(int* p, int n) {
    int max = *p;
    for (int i = 0; i < n; i++) {
        if (*p > max) {
            max = *p;
        }
        p++;
    }
    return max;
}

int findMin(int* p, int n) {
    int min = *p;
    for (int i = 0; i < n; i++) {
        if (*p < min) {
            min = *p;
        }
        p++;
    }
    return min;
}

int sumEven(int* p, int n) {
    int sum = 0;
    for (int i = 0; i < n; i++) {
        if (*p % 2 == 0) {
            sum = sum + *p;
        }
        p++;
    }
    return sum;
}

int main() {
    int arr[6] = {12, 5, 28, 9, 16, 3};
    int max = findMax(arr, 6);
    int min = findMin(arr, 6);
    int sum = sumEven(arr, 6);

    cout << "最大值 = " << max << endl;
    cout << "最小值 = " << min << endl;
    cout << "偶数之和 = " << sum << endl;
    return 0;
}
```

```text
最大值 = 28
最小值 = 3
偶数之和 = 56
```

三个函数的结果跟踪：

| 访问元素 | `findMax` 当前最大值 | `findMin` 当前最小值 | `sumEven` 当前和 |
|---:|---:|---:|---:|
| 12 | 12 | 12 | 12 |
| 5 | 12 | 5 | 12 |
| 28 | 28 | 5 | 40 |
| 9 | 28 | 5 | 40 |
| 16 | 28 | 5 | 56 |
| 3 | 28 | 3 | 56 |

**为什么三个函数互不影响指针位置？** 每次调用 `findMax(arr,6)`、`findMin(arr,6)`、`sumEven(arr,6)` 都创建新的局部形参 `p`，从 `arr[0]` 的地址开始。函数内的 `p++` 不改变 main() 的数组，也不会改变其他函数中后来创建的指针形参。

> 此示例中 `n=6`，数组非空。如果要写成通用函数，需要另外考虑 `n<=0` 时能否使用 `*p` 初始化的问题。

### 综合复习⑩：指针同时查找 max / min（答对 A）

```cpp
int arr[5] = {16, 7, 25, 3, 12};
int* p = arr;
int max = *p;
int min = *p;
for (int i = 0; i < 5; i++) {
    if (*p > max) max = *p;
    if (*p < min) min = *p;
    p++;
}
```

| i | p 指向 | `*p` | max 更新后 | min 更新后 |
|---:|---|---:|---:|---:|
| 0 | arr[0] | 16 | 16 | 16 |
| 1 | arr[1] | 7 | 16 | 7 |
| 2 | arr[2] | 25 | 25 | 7 |
| 3 | arr[3] | 3 | 25 | 3 |
| 4 | arr[4] | 12 | 25 | 3 |

输出 `max`、`min`、`arr[1]`：

```text
25
3
7
```

**重点：** 两个 `if` 是独立判断，不是 `if-else`；`max = *p` 和 `min = *p` 均只修改统计变量，不修改数组。

## 五、集中整理：高频易错点

| 容易混淆的写法 | 正确理解 |
|---|---|
| `a` 与 `&a` | 一个是值，一个是地址 |
| `p` 与 `*p` | 一个是指针保存的地址，一个是所指对象 |
| `int* p` 与 `*p` | 前者声明指针，后者是解引用表达式 |
| `p++` 与 `(*p)++` | 前者移动指针，后者增加当前元素的值 |
| `p++` 与 `i++` | 前者控制指针位置，后者控制循环变量 |
| `max = *p` 与 `*p = max` | 前者修改 max，后者修改数组元素 |
| `sum += *p` 与 `*p += 10` | 前者修改 sum，后者修改数组元素 |
| `if ... if ...` 与 `if ... else ...` | 前者两个判断均会检查，后者仅执行一个分支 |
| 函数内 `p++` 与 main 中的 `p++` | 改的是不同作用域的指针变量 |
| 数组最后元素后的位置 | 可形成末尾后指针，但不能解引用 |

### 读指针题的固定五步法

1. **看初始数据**：列出 `arr`、指针起点、`max/min/sum` 初值。
2. **看指针指向**：每轮先确认 `p → arr[几]`，再得到 `*p` 的值。
3. **看分支**：把 `*p` 代入 `if` 条件，明确真或假。
4. **看赋值方向**：究竟修改 `*p`、`max`、`min`，还是 `sum`？
5. **看两个自增**：先按代码顺序执行 `p++`、`i++`，再进入下一轮。

# Day 4：运算符优先级与条件判断

## 一、知识点①：算术运算符优先级

C++ 中不同运算符具有不同的优先级，优先级高的先计算。

| 运算符 | 含义 | 优先级 |
|---|---|---|
| `*` | 乘法 | 高 |
| `/` | 除法 | 高 |
| `%` | 取模 | 高 |
| `+` | 加法 | 低 |
| `-` | 减法 | 低 |

记忆口诀：先乘除取模，后加减。

相同优先级的双目算术运算符通常按照从左到右的顺序结合。

### C++ 示例

```cpp
int result = 2 + 3 * 4;
cout << result << endl;  // 输出 14
```

计算过程：

2 + 3 × 4 = 2 + 12 = 14

## 二、知识点②：括号改变运算顺序

- `()`：可以改变正常的运算顺序。
- 括号里面的内容优先计算。
- 使用括号可以让复杂表达式更加清晰。

### C++ 示例

```cpp
int result = 2 + 3 * 4;
cout << result << endl;    // 输出 14

int result2 = (2 + 3) * 4;
cout << result2 << endl;   // 输出 20
```

注意：括号可以改变原本的运算顺序。

## 三、知识点③：嵌套括号

- 当表达式中出现多个嵌套括号时，需要从最里面的括号开始计算。
- 先计算内层括号，再逐层向外计算。
- 最后按照运算符优先级完成剩余计算。

### C++ 示例

```cpp
int x = (10 - (6 / 2)) * 2;
cout << x << endl;  // 输出 14
```

计算过程：

1. 最里面的括号：6 / 2 = 3
2. 外层括号：10 - 3 = 7
3. 最后计算乘法：7 × 2 = 14

最终输出：14

## 四、知识点④：关系运算符（比较运算符）

关系运算符用于比较两个数的大小或判断两个数是否相等。

### 1. 常见关系运算符

| 运算符 | 含义 | 示例 |
|---|---|---|
| `>` | 大于 | `a > b` |
| `<` | 小于 | `a < b` |
| `>=` | 大于等于 | `a >= b` |
| `<=` | 小于等于 | `a <= b` |
| `==` | 等于 | `a == b` |
| `!=` | 不等于 | `a != b` |

### 2. 比较结果

- `true`：条件成立。
- `false`：条件不成立。
- C++ 默认输出 `true` 为 `1`，`false` 为 `0`。

### 3. 特别注意：= 和 == 的区别

- `=`：赋值运算符，把右边的值赋给左边。
- `==`：关系运算符，判断左右两边是否相等。

### C++ 示例

```cpp
int a = 8;
int b = 10;

cout << (a > b) << endl;   // 输出 0
cout << (a == b) << endl;  // 输出 0
cout << (a != b) << endl;  // 输出 1
```

## 五、知识点⑤：if 条件判断

- `if`：用于判断一个条件是否成立。
- `if (条件)`：条件成立时，执行大括号 `{}` 中的代码。
- 条件不成立时，跳过 `{}` 中的代码。
- 条件通常使用比较运算符，例如 `>`、`<`、`==`、`>=`。
- `{}` 用来包围条件成立后需要执行的语句。

### 1. 基本语法

```cpp
if (条件) {
    // 条件成立时执行
}
```

### 2. C++ 示例

```cpp
#include <iostream>
using namespace std;

int main() {
    int score = 85;

    if (score >= 60) {
        cout << "Pass" << endl;
    }

    return 0;
}
```

运行结果：

```text
Pass
```

因为 85 大于等于 60，所以条件成立，执行 `if` 内部的代码。

### 3. 多个独立的 if

多个独立的 `if` 可以分别进行判断，前一个 `if` 是否成立不会影响后一个 `if` 的判断。

```cpp
int score = 75;

if (score >= 60) {
    cout << "Pass" << endl;
}

if (score >= 90) {
    cout << "Excellent" << endl;
}
```

运行结果：

```text
Pass
```
